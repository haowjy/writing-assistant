# Write reusable follow-up conversations

Background agent p47 was asked to create user messages that continue a writing collaboration after its opening request, including corrections of assumptions the agent had never stated. It completed 36 scripts containing 210 follow-up messages and verified their structure and coverage without running a model.

## Conversation length and kinds of feedback

A “steer” is one user follow-up message; a script is an ordered sequence of steers. Each of three depth bands contains 12 scripts. Scripts with 2–3 steers contain 27 messages in total; scripts with 4–6 contain 52; scripts with 8–12 contain 131. Equal coverage was interpreted as equal script counts, 12/12/12, so longer scripts necessarily contribute more messages. Equal message volume would require rebalancing.

Every band contains all nine feedback kinds. Overall there are 46 `ADD_CONSTRAINT` messages, which add requirements; 29 `PUSH_BACK`, which object to a choice; 29 `APPROVE`, which accept work or direction; 26 `REQUEST_REVISION`, which ask to revise work; 22 `CHANGE_DIRECTION`, which redirect it; 19 `NEW_MATERIAL`, which supply story material; 14 `CLARIFY_ANSWER`, which answer a clarification; 14 `SCOPE_CUT`, which reduce scope; and 11 `INTERRUPT`, which interrupt the current task. The companion's band-by-kind table records the distribution.

Each script records “response pressure”, meaning whether the next response should ask or proceed. Fifteen scripts use `PERMITS_DEFAULT`, allowing a stated default; 12 use `MUST_NOT_ASK`, requiring action on an already clear or delegated choice; and nine use `REQUIRES_ASK`, requiring clarification of an unresolved decision. Each has a reason. These distinctions are based on the visible message, not on private model reasoning.

Ten scripts belong to `silent_assumption`, where the writer notices a choice the agent made without saying so. Three are in the 2–3 band, three in 4–6 and four in 8–12. Each has a `tests` field naming the assumption: strangers rather than acquaintances, unrequested romance, action assigned to the wrong character, an unreliable narrator, night rather than day, an off-screen death, an abandoned place, improper knowledge of a secret, an unapproved season, or an invented backstory death.

There are 191/210 terse messages, defined as fewer than 12 words, against a minimum of 25%. The original agent report calls this 90%; the companion calls it 91%. Both refer to the same count, about 90.95%, so the percentage discrepancy is retained as a reporting issue. Messages range from one-word replies such as “Good.” and “Both.” to about 16 words.

Six scripts sustain or escalate conflict without a quick resolution, meeting the requirement of at least six: SS-A08, SS-B04, SS-B12, SS-C05, SS-C06 and SS-C09. These identifiers locate individual scripts; A, B and C correspond to the three depth bands.

## Data format and checks

Scripts use `{protagonist}`, `{other}`, `{object}` and `{place}` placeholders for the main character, second character, story object and setting so they can be reused with different worlds. The per-script fields are `id`, `group`, `depth_band`, `n_steers`, `response_pressure`, `rationale` and `steers[]`. Assumption scripts also carry `tests`; applicable scripts carry `escalates_conflict`. Every steer contains `text` and `kind`.

The JSON parses and has `schema_version: 1`. Checks confirmed that every message uses one of the nine permitted kinds, every script has one of the three response-pressure values and a non-empty rationale, and `n_steers` equals the actual sequence length. The three band ranges were enforced; every band was populated and contained all nine kinds. Searches for literal world names such as `Mara`, `Ilan`, `tidal` and `ledger` found no names, only a false match within “haven't”. The scripts use placeholders. Both required outputs were checked as non-empty and their sizes confirmed.
