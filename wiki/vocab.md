# Vocabulary

| Term | Meaning |
|---|---|
| Authoring agent | A conversational collaborator that plans, writes, revises, and uses project state. |
| Authoring workspace | External files carrying a creative project's prose, notes, plans, and decisions. |
| Trajectory | An ordered interaction containing messages, tool calls, observations, and outputs. |
| Canon | Story facts and decisions treated as committed for the project. |
| Semantic beat | A local unit of narrative development used as a candidate planning or writing boundary. |
| Writer / realizer | The responsibility for turning a local plan into prose; the names are aliases. |
| Explicit / implicit / deferred | Information stated on the page, left inferable, or held for later. |
| Agent performance | How well the collaborator follows instructions and manages the authoring process. |
| Artifact performance | The quality of the resulting writing. |

See [authoring workspace](authoring-workspace.md), [trajectory data](trajectory-data.md),
and [evaluation](evaluation.md) for their use in the research.
