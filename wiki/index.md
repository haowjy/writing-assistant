# Creative-writing research

The project studies agents that collaborate with writers across long-running
stories, using external project files to maintain decisions and continuity.

- [Project goals](project-goals.md): intended capabilities and research questions.
- [Authoring workspace](authoring-workspace.md): project state and the writing loop.
- [Trajectory data](trajectory-data.md): what an authoring interaction must capture.
- [Evaluation principles](evaluation.md): collaboration and prose as separate outcomes.
- [Vocabulary](vocab.md): shared terms.

Proposed experiments and execution checklists live in the
[research work plan](../work/research-plan/index.md). For running the code, use the
[README](../README.md). The [source snapshot](sources/original-research.zip) contains
the original research documents.
